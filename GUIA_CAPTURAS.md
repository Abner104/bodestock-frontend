# 📸 GUÍA PARA TOMAR CAPTURAS DE PANTALLA

Sigue estos pasos para tomar las capturas que necesitas para el tutorial interactivo.

## 🛠️ PREPARACIÓN

### Herramienta recomendada: Recortes de Windows
1. Presiona `Windows + Shift + S`
2. Selecciona el área a capturar
3. Se guarda en el portapapeles
4. Abre Paint (`Windows + R` → escribe `mspaint`)
5. Pega con `Ctrl + V`
6. Guarda con el nombre indicado abajo

### IMPORTANTE:
- **Resolución**: 1920x1080 (pantalla completa)
- **Formato**: PNG
- **Calidad**: Alta
- **Guardar en**: `C:\Users\Ultrabook\planilla-costos\tutorial-assets\`

## 💡 TIPS PROFESIONALES

1. **Limpia la pantalla**: Cierra pestañas innecesarias
2. **Usa datos de ejemplo**: No uses datos reales/sensibles
3. **Buena iluminación**: Si usas modo oscuro, asegúrate que se vea bien
4. **Centrado**: Captura la ventana completa del navegador
5. **Sin distracciones**: Cierra notificaciones de Windows
